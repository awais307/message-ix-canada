# MESSAGEix-Canada

This repository houses the MESSAGEix-Canada integrated assessment model. Developed by the research team at the Sustainable Energy Systems Integration & Transitions (SESIT) Group at the University of Victoria, the model follows a linear programming (LP) framework designed for strategic energy planning and the integrated assessment of energy systems. The model performs a least cost optimization across the thirteen different provinces and territories of Canada to achieve a comprehensive view of the interactions between the different regions.

## Installation and Getting Started

The MESSAGEix framework for Canada can be installed by following the instructions provided [here](https://sesit.gitlab.io/message-ix-canada/installation/). The documentation for MESSAGEix Canada contains all the important information for [getting started](https://sesit.gitlab.io/message-ix-canada/get_started/) with using the model.

## Documentation

The full documentation for MESSAGE-ix Canada can be found in the following [Read the Docs page](https://sesit.gitlab.io/message-ix-canada/), also linked to this repository. The global MESSAGE-ix framework documentation includes some useful tutorials which can be accessed [here](https://github.com/iiasa/message_ix/tree/main/tutorial).
