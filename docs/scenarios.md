# Scenarios

Scenarios are central to exploring different energy futures and policy outcomes. Users can create new scenarios by copying the baseline scenario folder and modifying the relevant files, or by setting up entirely new scenarios with their specific assumptions and inputs.

The `scenarios` directory is where all user-created scenarios are stored. This includes:

- **Baseline Scenario:** A common scenario that acts as the baseline for comparison with other scenarios.
- **User-Created Scenarios:** Each scenario has its own folder containing the necessary data and configuration files (e.g., `config.toml`).
- **Direct Air Capture Technologies:** A net-zero scenario that incorporates direct air capture technologies, which are a new type of emission-mitigating technology.
