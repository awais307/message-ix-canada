# Model Run

The `model_run.md` section guides users on how to execute the MESSAGEix-Canada model. 

The model can be run in two primary ways:

1. **Command Line:** Users can specify the scenario name corresponding to a folder containing the necessary data and a `config.toml` file. The model will read in these files, perform the necessary preprocessing, and then solve the scenario.

2. **Jupyter Notebook:** The model can also be run interactively using the `setup_scenario` function within a Jupyter notebook. This allows users to adjust parameters, explore data, and analyze results before and after solving the model.

Both methods are supported, providing flexibility depending on the user's preferred workflow. Make sure to follow the instructions specific to each method to ensure the model runs successfully.
