# MESSAGEix-Canada - An Open source Integrated Assesment Model

MESSAGEix-Canada is an open-source model designed to help understand and analyze energy and environmental pathways for Canadian provinces and territories. This model supports the exploration of different scenarios to achieve sustainable development and climate targets across Canada.

This documentation aims to provide a comprehensive guide to the usage and development of the MESSAGEix-Canada model, which is pivotal in shaping energy policies and strategies for a sustainable future in Canada.

## Project Layout

    data    # Folder with external data to the model (typically GDP and population profiles).
    docs    # Folder with the documentation pages
    model   # Folder with model information
        ./notebooks   # Folder with Jupyter notebooks used for development and example formulations
        ./policies    # Folder with Python scripts which are used to implement different policies in the model
        ./report      # Folder with report files and report benchmarks for the model
        ./scenarios   # Folder with different scenario subfolders
            ../baseline    # Baseline scenario (business as usual cases)
            ../dacs        # Net-zero scenario with direct air capture (DAC) technologies added
            ../hydrogen    # Scenario with different hydrogen technologies added
            ../netzero     # Simple net-zero scenario
            ../netzero_opt # Optimistic net-zero scenario
            ../netzero_pes # Pessimistic net-zero scenario
        ./utilities   # Folder with Python nscripts used for different miscelaneous purposes in the model
    output          # Folder with output Excel files from the model
    reporting_outputs   # Folder with Excel files generated by the model reporter (more detailed outputs)
