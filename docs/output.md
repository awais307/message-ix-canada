# Output

The `output` directory contains all outputs generated by the post-processing functions in MESSAGEix-Canada. This includes:

- **Scenario Results:** Outputs such as CSV files and Excel files generated after solving a scenario.
- **Reports:** Any reports generated by the post-processing tools, providing summaries and visualizations of the scenario outcomes.

These outputs are essential for interpreting the results of the model runs. Users can use these files to analyze the impacts of different scenarios, compare outcomes, and inform decision-making processes.
